🍕 Cracking the Crust: A 48K+ Row Pizza Sales Analysis with SQL
Welcome to Cracking the Crust, a real-world business intelligence project that dives deep into 48,000+ rows of pizza sales data using MySQL, Pandas, and Python. This project uncovers key insights through SQL queries, helping stakeholders understand sales trends, customer behavior, and performance metrics.

📊 Project Overview
Goal: Analyze historical pizza sales data to extract business KPIs and trends for data-driven decision-making.

Tech Stack:

MySQL – Data storage, schema creation, and querying

Pandas – Data cleaning and manipulation

Python – Scripting for ETL and database upload

Excel (optional) – Pre-processing or initial inspection
